# Aggle Browser — Full Standalone macOS App

## Overview
Transform the Aggle extension into a standalone macOS .app that wraps LibreWolf with the complete glassmorphism design, native AI sidebar, and all features built in. One click to install and run.

---

## Architecture

```
Aggle.app/
├── Contents/
│   ├── Macos/
│   │   └── aggle-launcher      # Python launcher
│   ├── Resources/
│   │   ├── chrome/
│   │   │   ├── userChrome.css  # Complete glass chrome (rewritten)
│   │   │   └── userContent.css # New tab + context menus (enhanced)
│   │   ├── aggle-extension.xpi # Built extension
│   │   └── Aggle.icns          # App icon
│   └── Info.plist
```

**Launcher flow:**
1. Creates/verifies Aggle profile at `~/Library/Application Support/Aggle/`
2. Copies chrome files into `<profile>/chrome/`
3. Writes `user.js` with LibreWolf + Aggle preferences
4. Extracts and installs the Aggle extension into the profile
5. Launches LibreWolf with `--profile ~/Library/Application\ Support/Aggle/`

## Phase 1: Chrome CSS Overhaul (userChrome.css)

**Current:** Firefox default tab+nav merged into one toolbar.
**Target:** Safari-like two-row layout.

### Layout Structure
```
┌─────────────────────────────────────────────────────┐
│  ●  GitHub  YouTube  Reddit      [+]  [≡]          │  ← Tab strip (36px, glass)
├─────────────────────────────────────────────────────┤
│ ← → ⟳   🦆 [https://example.com              ] ⭐  📌 │  ← Nav bar (44px, glass)
├─────────────────────────────────────────────────────┤
│                                                     │
│                    page content                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### CSS Changes
- `#navigator-toolbox` → CSS grid with 2 rows (tabs on top, nav below)
- `#TabsToolbar` → thin glass strip, `backdrop-filter: blur(32px)`, specular top highlight
- Tabs → rounded pills, ember gradient on selected, hide close button until hover
- `#nav-bar` → wider glass bar, `blur(28px)`, subtle divider from tab strip
- `#urlbar-container` → centered glass pill (~60% width, max 700px)
  - Engine icon button on left (🦆/G/B)
  - URL input in center
  - Star + sidebar toggle on right
  - Focus: orange glow ring `box-shadow: 0 0 0 3px rgba(255,90,31,0.15)`
- `#sidebar-box` → native sidebar, glass panel matching design language
- `#PersonalToolbar` → hidden by default (cleaner look)
- Context menus, tooltips, panels → all glass-styled (already partial)

### Files Changed
- `chrome/userChrome.css` → **complete rewrite** (~400 lines)
- `chrome/userContent.css` → enhanced (better new tab integration, sidebar styles)

## Phase 2: Launcher .app

### 2.1 Python Launcher (`launcher/aggle-launcher`)
```python
#!/usr/bin/env python3
# Sets up Aggle profile, installs extension, launches LibreWolf
PROFILE = Path.home() / "Library/Application Support/Aggle"
# 1. Create profile + chrome/ + extensions/
# 2. Copy userChrome.css, userContent.css → profile/chrome/
# 3. Write user.js with prefs
# 4. Extract XPI → profile/extensions/aggle@aggle.dev/
# 5. subprocess.launch("/Applications/LibreWolf.app", --profile PROFILE)
```

### 2.2 Info.plist
Standard macOS app manifest:
- CFBundleIdentifier: `com.aggle.browser`
- CFBundleExecutable: `aggle-launcher`
- LSMinimumSystemVersion: `13.0` (Ventura+)

### 2.3 XPI Packaging
- Build extension with `npm run build`
- Zip into `.xpi` (standard WebExtension format)
- Bundle in `Resources/aggle-extension.xpi`

### Files Created
- `launcher/aggle-launcher`
- `launcher/Info.plist`
- `launcher/Aggle.icns` (from existing SVG icon)
- Build script `scripts/package-app.sh`
